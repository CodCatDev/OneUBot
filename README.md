# Attention
Use the bot with caution, because Telegram does not trust bots, and if you notice strange activity, you may be banned. I do not bear responsibility for this, but I warned you about it

# How to use

1. Clone repo `git clone https://github.com/CodCatDev/OneUBot.git`

2. Open dir `cd OneUBot`

3. Install requirements `pip3 install -r requirements.txt`

4. Open Bot Dir `cd src`

5. Get API_ID and API_HASH on [my.telegram.org](https://my.telegram.org)

6. Save API_ID and API_HASH, and PHONE_NUMBER in `config.py` file

7. Run `python3 main.py` and complete the log-in steps in console
